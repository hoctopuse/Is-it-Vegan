## Rôle des sources

Les quatre PDF sont les sources réglementaires locales utilisées pour constituer et vérifier le référentiel multilingue de l’annexe II-B, sous CELEX `02008R1333`, consolidation `18.08.2026` :

- le PDF FR fournit les dénominations officielles françaises ;
- le PDF NL fournit les dénominations officielles néerlandaises ;
- le PDF EN fournit les dénominations officielles anglaises ;
- le PDF DE fournit les dénominations officielles allemandes.

Le fichier `EU_ADDITIVES_OFFICIAL_MULTILINGUAL_REFERENCE.csv` situé dans ce même dossier est la table de référence structurée : 340 numéros E uniques, noms officiels disponibles, statuts de vérification et provenance CELEX. Il ne contient aucun statut vegan.

Les rapports d’acquisition et de complétion restent à la racine du dépôt : `EU_ADDITIVES_OFFICIAL_MULTILINGUAL_ACQUISITION_REPORT.md` et `EU_ADDITIVES_REFERENCE_0_6_9_10_COMPLETION_REPORT.md`.
