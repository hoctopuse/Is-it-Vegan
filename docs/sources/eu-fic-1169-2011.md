# Règlement FIC — CELEX 02011R1169

Le règlement (UE) n° 1169/2011 sur l’information des consommateurs (FIC) est une source de contexte réglementaire pour l’analyse d’étiquettes. Les quatre consolidations locales du 01.04.2025 en français, néerlandais, anglais et allemand restent les sources primaires.

`tools/extract_fic_reference.py` produit les copies UTF-8 page par page, les extraits thématiques et le manifeste dans `reference-input/eu-food-labelling/00-general-food-labelling/`. Il n’importe aucune donnée applicative : les catégories et déclarations du règlement ne sont pas, à elles seules, des ingrédients ni des preuves d’origine vegan.

L’annexe II (pages 36–37 de l’édition EN) est utile pour repérer les déclarations d’allergènes et leurs exceptions. Elle ne change pas le traitement existant : une ligne « peut contenir » reste une trace, exclue du verdict. Les futures passes pourront revoir les candidats recensés dans `EU_FIC_1169_2011_DOCUMENTATION_AND_KNOWLEDGE_AUDIT.md`, avec une source de classification indépendante lorsque nécessaire.

Commandes reproductibles :

```text
python tools/extract_fic_reference.py --write
python tools/extract_fic_reference.py --check
```
